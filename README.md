# Hermes for Daniel

A personalized, interactive field guide for learning and operating [Hermes Agent](https://hermes-agent.nousresearch.com/docs).

## Live site

**https://danielt69.github.io/hermes-for-daniel/**

## Features

- Searchable Hermes onboarding guide
- Tools, skills, profiles, memory, MCP, delegation, cron, and gateway guidance
- M5 Max-specific recommendations
- Accessible dark and light themes
- Persistent progress checkboxes
- Compact and comfortable reading modes
- Copyable commands and workflow templates

## Run locally

Open `index.html` directly in a browser, or run a static server:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Source

The site is intentionally dependency-free: one self-contained HTML file with embedded CSS and JavaScript.
