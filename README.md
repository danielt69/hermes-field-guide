# Hermes Field Guide for Daniel

A personalized, interactive onboarding guide for [Hermes Agent](https://hermes-agent.nousresearch.com/docs), tailored to Daniel Tsionit's AI-native product and frontend engineering workflows.

## Live site

https://danielt69.github.io/hermes-field-guide/

## Features

- Practical Hermes mental model and first-session tutorial
- Tool, skill, memory, profile, MCP, delegation, and automation guidance
- Prioritized setup recommendations for an Apple M5 Max MacBook Pro
- Reusable research, coding, and multi-agent workflow contracts
- Search, progress tracking, light/dark themes, and compact reading mode
- Accessible typography, WCAG AA color contrast, keyboard focus states, and reduced-motion support

## Local use

Open `index.html` directly in a browser. No build step or external dependency is required.

## Source

The guide is based on the current official [Hermes Agent documentation](https://hermes-agent.nousresearch.com/docs) and is maintained as a single self-contained HTML file.
